# Теннисный рывок 🎾
```
⚙ Необходимо: теннисный мяч
```
**Правила:** Все стоят по кругу лицом в центр. Аниматор ходит за кругом и в какой-то момент кладёт теннисный мяч на пол между двумя соседними игроками.

Эти двое сразу стартуют и оббегают круг снаружи в разные стороны. Кто первым вернётся и схватит мяч, тот победил.

Игра повторяется несколько раз с разными парами.

### уточнения:
1. Бежать можно только снаружи круга, срезать через центр нельзя.
2. Остальные игроки стоят на месте и не мешают бегущим.
