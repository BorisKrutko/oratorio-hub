# Судзуки 🛞
```
⚙ Необходимо: автомобильная покрышка, фишки или верёвки для разметки поля
```
**Правила:** Игроки делятся на несколько команд с равным числом игроков. Поле размечается в виде правильного многоугольника: у каждой команды своя сторона. Если команд 3, поле — треугольник, если 4 — квадрат, и так далее. В центре поля лежит автомобильная покрышка.

В каждой команде игроки получают номера от 1 и дальше по порядку. Номера одинаковые во всех командах, например в каждой команде есть свой «первый».

Судья выкрикивает номер, и игроки с этим номером из всех команд выбегают в центр. Их задача — перетащить покрышку за линию своей стороны. Команда, которая перетянула покрышку, получает +1 очко.

Судья может назвать сразу несколько номеров, например «2 и 4». Тогда из каждой команды выбегают игроки с этими номерами.

Если судья кричит **«Судзуки!»**, выбегают все игроки.

Побеждает команда, набравшая больше очков.

### уточнения:
1. Выбегать можно только по своему номеру. Если игрок выбежал не по своему номеру, очко его команде не засчитывается.
2. Толкать, бить и ставить подножки нельзя, можно только тянуть покрышку.
3. Покрышка считается перетянутой, когда она целиком за линией.
