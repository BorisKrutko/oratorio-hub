# Парные два флага 🙈🚩
```
⚙ Необходимо: верёвки, свисток, флаги для команд, повязки на глаза
```
> **Основа:** игра проходит по правилам [Двух флагов](../games/main_games/2_flaga.md): две команды, каждая на своей территории; чтобы заработать очко, нужно перебежать территорию соперника, схватить свой флаг в базе и принести его на свою территорию. Пятнать можно только на своей территории.

**Правила:** Внутри команды ребята делятся на пары. Одному игроку в паре завязывают глаза, второй становится **сопровождающим** и отвечает за своего игрока.

- **Игрок с завязанными глазами** делает всё сам: бежит за флагом, берёт флаг, пятнает соперников.
- **Сопровождающий** может касаться своего игрока, подсказывать и даже вести его за руку, но **не имеет права** пятнать и брать флаг.

**Заморозка:** если игрок с завязанными глазами коснулся сопровождающего или игрока соперников с завязанными глазами, при любом касании пара замораживается и стоит на месте. Распятнать замороженную пару может только игрок с завязанными глазами из своей команды.

### уточнения:
1. флаг передавать нельзя
2. если пару запятнали, соперники могут стоять минимум в метре от неё
3. если пару запятнали с флагом, флаг остаётся у игрока в руках
