# Ребёнок, Стул, Рюкзак 🎶
```
⚙ Необходимо: музыка, чётное число игроков
```
**Правила:** Играет музыка, все свободно ходят по залу. Во время ходьбы судья называет одну из трёх команд — **Ребёнок**, **Стул** или **Рюкзак**. Игроки должны быстро найти себе пару и выполнить названный элемент:

- **Ребёнок** — один игрок берёт другого на руки.
- **Стул** — один игрок становится на руки и колени, второй садится ему на спину.
- **Рюкзак** — один игрок берёт другого на спину.

Последняя пара, которая выполнила элемент, выбывает. Игра продолжается, пока не останется одна пара — она побеждает.

**Важно:**
- Каждый раз нужно менять пару — с одним и тем же игроком дважды подряд вставать нельзя.
- Заранее выбирать пару нельзя — пара ищется только после команды судьи.
