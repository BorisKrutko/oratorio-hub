# 🎲 Игры оратория

Здесь собраны игры, в которые мы, аниматоры салезианского оратория, любим играть с детьми. Есть правила подвижных и больших игр, игры для весёлых вечеров, квизы и др. материалы.

Всё записано так, чтобы любой аниматор мог открыть правила и сразу провести игру.

## 📊 Таблицы

| Что | Ссылка | Зачем |
|---|---|---|
| 📅 Журнал игр | [Google Sheets](ССЫЛКА_НА_ЖУРНАЛ) | Отмечаем, во что и когда играли на весёлых вечерах и в больших играх |
| 💡 Идеи | [Google Sheets](ССЫЛКА_НА_ИДЕИ) | Кидаем рилсы и ссылки с новыми идеями для весёлых вечеров и больших игр |

**Журнал игр.** В таблице две вкладки:
- **Весёлые вечера**: дата, игра, кто вёл, как прошло.
- **Большие игры**: дата, игра, модификация, кто вёл, как прошло.

**Идеи.** В таблице две вкладки:
- **Весёлые вечера**: ссылка на рилс, короткое описание, кто предложил, статус (новая / попробовали / в базе).
- **Большие игры**: те же колонки.

Если идея прижилась, запишите её правила в репозиторий и поставьте статус «в базе».

## ✍️ Как добавить игру

1. Создайте файл `название_латиницей.md` в нужной папке.
2. Используйте такой шаблон:

   ````markdown
   # Название 🎯
   ```
   ⚙ Необходимо: что нужно для игры
   ```
   > **Правила:** коротко, как играть.

   ### Уточнения:
   1. ...
   ````

3. Модификацию игры положите в папку этой игры. Под заголовком напишите `## модификация <игры>` и дайте ссылку на основные правила, чтобы их не переписывать.
